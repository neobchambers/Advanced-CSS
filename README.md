# Front-End Development - Assignment #2: Advanced CSS (Flexbox & Grid)
Imanova Yerkezhan
SE-2528
The goal of this assignment is to understand and apply advanced CSS layout techniques using Flexbox and CSS Grid. By the end, students will be able to build complex, responsive layouts without relying on floats or external frameworks. This assignment emphasizes modern layout practices, alignment, responsiveness, and design efficiency. 

The project is structured as a multi-page web application linked together via a unified navigation bar.

Repository Structure:

index.html - Portfolio Page (Task 4)
Combines Flexbox and CSS Grid. It features a responsive layout with project cards on the left (arranged with Grid & Flexbox) and a personal info sidebar on the right.

cards.html - Card Row (Task 1)
Demonstrates Flexbox capabilities (flex-direction, gap, align-items: stretch). Displays course cards with equal height, uniform spacing, and a clean hover effect.

layout.html - Page Layout with Grid Areas (Task 2)
Showcases grid-template-areas by defining a classic web dashboard structure: a header, sidebar, main content area, and a footer.

gallery.html - Image Gallery (Task 3)
A 3x3 photo gallery built using CSS Grid (repeat(), minmax()). Features smooth hover overlays with image captions.

style.css - Main stylesheet containing all custom layout rules, animations, and responsive breakpoints.
